# Mon Blog - IT 130

Projet réalisé dans le cadre de l'UE **IT 130 - Introduction aux Technologies Web**.

**Auteur :** Victoire AGBALI

## Description

Petit site web composé de trois pages, construit semaine après semaine :

| Fichier | Description |
|---|---|
| `index.html` | Page d'accueil (Semaine 1) |
| `blog.html` | Page de blog (Semaine 2) |
| `contact.html` | Page de contact (Semaine 3) |

## Contenu de la page de contact (Semaine 3)

- Un formulaire HTML5 complet avec des champs `text`, `email`, `tel`, `select`, `textarea` et `checkbox`.
- Des étiquettes `<label>` associées à chaque champ (attributs `for` et `id`).
- La validation native HTML5 : `required`, `minlength` et `pattern`.
- Un tableau « Mes disponibilités » et un tableau « Mes compétences », avec `caption`, `thead`, `tbody`, `tfoot` et `th scope`.
- Une vidéo et un fichier audio intégrés, avec un texte de repli pour les navigateurs qui ne les supportent pas.

## Accessibilité

- Labels associés à tous les champs de formulaire.
- Textes de repli pour la vidéo et l'audio.
- Un seul titre `<h1>` par page, avec des titres dans l'ordre.
- En-têtes de tableaux avec l'attribut `scope`.
